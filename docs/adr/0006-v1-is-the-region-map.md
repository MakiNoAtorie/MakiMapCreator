# v1 is the region map

v1 ships the region map as a complete product on its own: generate, edit, entities, pages and export, with the region map as a root map. Phase 0 builds a crude world map only to prove the parent-to-child link. The order after that is world map, then settlement map, then dungeon map.

The region pipeline (terrain, water, rivers, climate, biomes) carries the most technical risk and the most reference research. The world map's coarse geography is the same pipeline at low resolution, and the political generator needs its terrain costs. So building the region map first gives the world map its base.
